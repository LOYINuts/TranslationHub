## 二、背景故事

Remiel 来自高岩省途歇城，是一名年轻的布莱顿工程师。她在高岩时就对**矮人（锻莫）文明**产生了浓厚的兴趣，足迹遍布高岩境内的矮人遗迹，积累了丰富的矮人机械知识。在探索完高岩的遗迹后，她将目光投向了天际省——这里有着更多未被充分发掘的矮人遗迹。

然而，她遇到了一个现实问题：**她并不擅长战斗**。在故事开始时，她在马卡斯的银血客栈遇到了龙裔，并请求帮助——矮人遗迹 Nchuand-Zel 已被一只 frostbite spider 盘踞，凭她一己之力无法进入。在龙裔的帮助下，她终于得以进入遗迹，并在那里制作/获得了她的矮人机械蜘蛛伙伴 **Scrap**。此后，她正式成为龙裔的随从，踏上了天际的冒险之旅。

## 三、性格特征

Remiel 的性格鲜明而多维，是她的模组深受欢迎的核心原因：

### 核心特质

| 特质 | 说明 |
|------|------|
| **直率 (Blunt)** | 说话不拐弯抹角，想到什么说什么 |
| **健谈 (Talkative)** | 非常爱说话，对几乎所有事物都有评论 |
| **容易兴奋 (Excitable)** | 对矮人发现、新地点、机械装置表现出热烈的兴奋感 |
| **开朗 (Cheerful)** | 整体语气阳光、积极，带来愉快的陪伴感 |
| **好奇 (Curious)** | 对矮人科技渴望探索，对天际省的各种事物也充满好奇 |
| **聪慧 (Intelligent)** | 作为工程师，她聪明且有扎实的专业知识储备 |
| **有魅力 (Charming)** | 尽管直言不讳，但有一种自然的亲和力和魅力 |

### 深层性格与世界观

- **不擅战斗**：这是角色核心设定。Remiel 明确表示自己不是战士，战斗中需要龙裔的保护。她是一个学者/工程师型角色，并非战士。
- **对盗贼行为态度积极**：偷窃、撬锁等技能对她来说很自然（"Thievery comes naturally to her"），她在这方面的态度比较随性。
- **布莱顿人的文化立场**：布莱顿人与高精灵（Altmer）和诺德人（Nord）之间有着复杂的历史关系，这会影响她的一些看法。她不会因为龙裔是诺德人或高精灵就讨厌对方，但最初会对此有一些疑虑。
- **对风暴斗篷的态度**：她对风暴斗篷持谨慎态度（wary），但如果龙裔与她坦诚交流为什么选择为乌弗瑞克而战（并且态度不恶劣），她能够理解龙裔的选择。
- **好感度系统**：模组有一套简约的好感度系统。初始为中立，在与她的各种对话中，根据龙裔的回应，她会逐渐更喜欢或更不喜欢龙裔。简单来说：**对她不好，她就不会喜欢你**。

### 细节补充

- **浪漫关系**：模组包含完整的恋爱与结婚系统。龙裔需要完成 "Upgrades" 任务，并听她讲述父亲和前任的故事后，才能开始调情（flirt）。调情选项积累达到 12 分后，她将成为可结婚对象。婚后她有独特的待机动作、会为龙裔做饭、经营一个小商店、接受礼物，还会和龙裔的孩子们拌嘴（banter with kids）。
- **与其他随从的互动**：通过兼容补丁，Remiel 可以和 Inigo、Lucien Flavius、Kaidan、Auri 等知名自定义随从进行跨模组对话。

## 四、能力与专长

### 战斗能力
| 项目 | 说明 |
|------|------|
| **自身战斗力** | 较弱。她不是前线战斗人员，需要龙裔保护 |
| **Scrap（机械蜘蛛）** | 可以入侵并重新编程矮人机械蜘蛛作为永久战斗宠物，是她的核心战斗贡献 |
| **治疗术** | 与龙裔友谊达到足够高度后，当龙裔生命值低于 40% 时，她会尝试为龙裔治疗 |
| **缴械机械** | 完成弩箭相关项目后，她能在龙裔与自身均未被发现的情况下学会缴械矮人机械的技能（通过法术实现） |

### 非战斗技能

| 技能 | 说明 |
|------|------|
| **撬锁** | Remi 可以撬锁。完成或跳过初始任务后，龙裔会获得一个法术，使用该法术（而非原版指令）即可让她撬锁 |
| **潜行** | 由于身体力量较弱，她学会了尽量不被敌人发现，并在潜行和规避陷阱方面有一定经验 |
| **炼金术（自酿药水）** | 她没有接受过正式的炼金训练，但她够胆量尝各种奇怪的材料并投入药锅。她自制的药水效果不太稳定——**有原版的基础效果 + 一个较强的副效果 + 一个代价高昂的第三效果**，结果可能是惊喜也可能是惊吓。在安全地点（客栈、玩家房屋）可以请她提供样品药水 |
| **魔法（恢复系）** | 作为布莱顿人，她有与生俱来的魔法天赋，虽然没有掌握更高级的魔法，但能用恢复系法术自保 |

### 其他功能

| 功能 | 说明 |
|------|------|
| **设置住所** | 可以告诉 Remi 在任何客栈或玩家房屋居住，遣散后她会回到那里生活 |
| **放松模式** | 可以让她在安全地点（客栈、房屋、城镇）放松。还可以给她买杯饮料一起放松 |
| **骑马** | 可以让她骑马，但进城前需要下马 |
| **项目系统 (Projects)** | 友谊足够高时，她会谈论正在做的项目并请求帮助。目前有三个项目，未来会增加 |
| **灯笼** | 完成必要项目后，在黑暗的室内外她会使用灯笼。可开关 |
| **跟随距离** | 三种距离可选：很近、中等、默认 |
| **称呼名字** | Remi 有特定一组称呼玩家的名字（不接受自定义请求） |
| **切换蜘蛛** | 可以通过对话让 Scrap 在战斗中停止或恢复行动 |

## 五、Scrap —— 矮人机械蜘蛛伙伴

Scrap 是 Remi 的矮人机械蜘蛛伙伴，也是她作为工程师能力的核心体现。

### 升级机制
每次 Remi 看到一个新的矮人遗迹，都会为如何编程 Scrap 带来灵感。Scrap 的强度取决于 Remi **见过多少个遗迹**，共分 5 级：

| 等级 | 效果 | 等级倍率 |
|------|------|---------|
| **1** | 基础矮人蜘蛛，等级倍率 0.8x 玩家等级 | 0.8x |
| **2** | 提升攻击强度，等级倍率 0.8x | 0.8x |
| **3** | 获得矮人蜘蛛闪电攻击，等级倍率 0.9x | 0.9x |
| **4** | 提升攻击强度，等级倍率 0.9x | 0.9x |
| **5** | 获得矮人蒸汽攻击，等级倍率 1.0x | 1.0x |

### 触发升级的遗迹地点
以下遗迹计入升级进度：

1. Mzulft（祖夫特）
2. Alftand（奥方坦德）
3. Ikrngthand（伊克恩斯坦德）
4. Kagrenzel（卡格雷泽尔）
5. Avanchnzel（阿范琴泽尔）
6. Bthardamz（巴萨丹兹）
7. The Aetherium Forge（埃瑟瑞姆熔炉）
8. Mzinchaleft（辛查莱夫特）
9. Raldbthar（拉尔德巴萨）
10. Arkngthamz（阿肯斯塔姆兹）

- **与风暴斗篷**：持谨慎态度，但愿意理解对方的立场

## 八、角色定位总结

Remiel 的角色定位可以概括为：

> **一位来自途歇的布莱顿女工程师，痴迷于矮人文明，活泼直率、话多且容易兴奋。她不是战士而是一名学者/技师，战斗中需要龙裔的保护，但她用自己的矮人机械知识——尤其是她的机械蜘蛛伙伴 Scrap——为队伍做出独特贡献。她是一个可恋爱可结婚的随从，拥有约 5000 句配音的超大对话量，可以通过好感度系统、项目系统和升级系统与玩家深度互动，是当前 Skyrim 自定义随从模组中最受欢迎的角色之一。**

> **翻译时的核心口吻要点：直率但不粗鲁，健谈且容易兴奋，语气中带着对矮人科技的热情和布莱顿式的好奇心。对自己不擅战斗这件事有自知之明，说话风格贴近一个年轻、聪明、有点话痨的工程师。**
